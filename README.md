# Signal — Real-Time Audio Engine (C++ / JUCE)

Signal is the low-latency, headless audio engine that powers the Loophole DAW.
It is responsible for:

- Audio device management
- Real-time audio graph execution
- Plugin hosting (VST3, CLAP, AU)
- Sample-accurate parameter automation
- IPC communication with the Pulse model layer and Aura UI

This repository is part of the Infinite Loop Audio ecosystem.
