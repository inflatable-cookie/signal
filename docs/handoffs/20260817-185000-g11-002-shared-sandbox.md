## Why It Matters

Products that want several instances of the same plugin under one sandbox
boundary still pay one child process each. That is correct crash isolation and
the wrong cost when runtime placement selects a shared boundary. Contract `014`
already owns the meaning; this lane implements it on the existing broker.
