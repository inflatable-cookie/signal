## What This Thread Was Doing

Northstar refresh and Atlas caught Signal's docs claiming plugin hosting was
still missing. That's wrong: CLAP, VST3, AU, and LV2 already host through the
adapter crates, `signal-plugin-sandbox`, and `signal-plugin-bridge`. The real
gap is that `LocalRuntimeHost` never hands those backends to the render plane
as a Pulse-facing assembly path.

This handoff is from the planning/orchestrator thread to one bounded
implementation thread for `g11.001`. You can start from this file without a
copied transcript or a second prompt.

## Why It Matters

Loophole and other consumers need one honest path: scan → placement → bridge
backend → render-plane audio. Until the host assembly owns that path, shipped
hosting stays trapped in crate tests and looks unfinished in the docs.
