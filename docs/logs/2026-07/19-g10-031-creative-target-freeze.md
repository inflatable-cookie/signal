# g10.031 Creative Target Freeze

Date: 2026-07-19
Status: Batch 31.2 complete
Scope: operator listening promotion and documentation only

## Decision

Freeze a reachable creative parameter space, not one comparator winner:

- `Dream` is the default centre. PaulXStretch defines its smooth, musical,
  broadly useful character across percussion, bass, vocals, pads, and mixes at
  `4x`, `8x`, and `16x`.
- `Spectral` retains the CDP `SPECTSTR` region as intentional exposed,
  vocoder-like decoherence. It is less generally exciting but remains useful.
- `Rough` retains the `Rrreeeaaa` region as conspicuous polyphase novelty. It
  is interesting but less generally useful than `Dream`.
- `Cyclic` retains the ReaReaRea / Akai-style region as an explicit character
  useful through about `8x`.
- `Cloud` remains the later upper-range evolving texture character.

Signal may select or blend internal owners. Consumers see one semantic
character selector plus shared `motion`, `detail`, and `space` controls. This
is not an algorithm menu and does not require one compromised setting to
average incompatible references.

## Rejection Boundary

Neutral `Dream` fails if vocoder colour, rough periodicity, or cyclic repetition
leaks into it. `Spectral` and `Rough` fail if they are merely degraded Dream
rather than stable, recognizable, useful destinations. Any character fails on
uncommanded clicks, dropouts, arbitrary level changes, hard owner seams, or
unrelated channel motion. Commanded cyclic repetition and deliberate spectral
exposure are valid only inside their selected character.

External comparators cannot validate Signal's overlap transitions because they
do not implement its router. Below/inside/above overlap probes remain mandatory
when adjacent Signal owners reach admission.

Stereo remains unassessed and still requires an independent eligible listener.

## Boundary

No DSP, candidate harness, fixture, report mode, public API, Loophole, or Chorus
surface changed. Batch 31.3 is ready for one complete architecture brief; no
candidate implementation is authorized yet.
